We use five independent codebooks per English model. For model $Q_k$ and replicate $r=0,\ldots,4$, the C++ \texttt{mt19937\_64} seed is $202611190000+100k+r$. Each replicate generates $\max_N M_N$ independent length-24 strings. At length $N$, it uses the first $M_N$ entries truncated to $N$ letters; this preserves the required i.i.d. law at every length while correlating estimates across lengths. The standard error is the sample standard deviation of the five recovery fractions divided by $\sqrt5$. Plotted bands of two standard errors are descriptive pointwise Monte Carlo bands, not simultaneous or exact $95\%$ confidence intervals. The four transition tables contain 23 empty three-letter-context rows and no empty lower-order rows; the specified suffix fallback handles these rows.
